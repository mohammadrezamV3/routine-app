## ۰. زیرساخت مشترک (قبل از همه)

- [ ] **معماری:** یک اپ Next.js با تشخیص بخش بر اساس host در middleware
- [ ] **ورود مشترک:** کوکی نشست روی دامنه‌ی اصلی (`.arion…`) و یک Google OAuth callback روی دامنه‌ی اصلی
- [ ] **جابه‌جایی با لوگو:** ناوبری کامل مرورگر بین سه ساب‌دامین، با حالت انتقال
- [ ] **منوی همبرگری جدا برای هر بخش** (فقط آیتم‌های همان بخش)
- [ ] **لوگوها:** Arion | Routine، Arion | Workout، Arion | Trade
- [ ] **گیت‌ها:** فلگ و `requireModule` برای هر بخش (طبق CLAUDE.md، سمت سرور هم)
- [ ] **توسعه‌ی محلی:** راه تست سه ساب‌دامین روی localhost
- [ ] **زیرساخت دیپلوی:** DNS و Nginx برای سه ساب‌دامین (⏳ دیپلوی Docker+Nginx هنوز راه‌اندازی نشده)
- [ ] **CLAUDE.md:** به‌روزرسانی بعد از تغییر معماری (ساختار، ورود، ناوبری، قوانین بخش‌ها)
- [ ] **موتور XP مشترک** برای هر سه بخش (قوانین کسب، سطح، نوار پیشرفت، جلوگیری از امتیاز غیرواقعی)
- [ ] **⏳ مربی هوش مصنوعی (نومو):** یک موتور مشترک یا سه نام و موتور جدا؟ سهمیه و قیمت آن در پلن‌ها
- [ ] **⏳ اشتراک‌ها و پلن‌ها:** توضیح داده نشده؛ بعدا

## ۴. تصمیم‌ها و تناقض‌ها (باید تکلیفشون روشن شه)

1. **⏳ مجوز TradingView و داده‌ی بازار:** برای ابزارهای رسم، اندیکاتورها، بک‌تست و قیمت لحظه‌ای لازم است. بدون مجوز، نسخه‌ی ساده‌ی چارت با داده‌ی محدود.
2. **⏳ چک‌لیست ناقص و قانون ثبت:** لیست ترید می‌گوید «جلوگیری از ثبت معامله بدون تکمیل موارد اجباری، در صورت فعال‌بودن». CLAUDE.md می‌گوید ناقص بودن نباید ثبت را بگیرد. باید تصمیم بگیریم.
3. **⏳ رقابت و جدول رتبه‌بندی (ورزش):** بعدا اضافه می‌شه؛ قانون فعلی لیدربورد را کنار می‌زند و باید در CLAUDE.md به‌روز شه.
4. **⏳ نومو:** یک موتور مشترک برای هر سه بخش یا موتور جدا؟ سهمیه و پلن.
5. **⏳ موتور بک‌تست خودکار:** نیاز به طراحی جدا (اجرای قوانین روی داده‌ی تاریخی، هزینه‌ها، جلوگیری از دیدن داده‌ی آینده).
6. **⏳ مربی ورزشی:** سیستم منتور موجود استفاده می‌شه؛ بهینه‌سازی‌ها باید لیست شن.
7. **⏳ اشتراک‌ها و پلن‌ها:** توضیح بعدا داده می‌شه.

## ۶. قواعد ثابت (از CLAUDE.md، در هر مرحله رعایت شه)

- هیچ عدد فارسی یا اعراب در متن، کامنت و کامیت.
- هیچ‌وقت «أ» و «إ»، و هیچ‌وقت عبارت «بدون کارت بانکی».
- هر روت API بخش پولی: `requireModule` و `featureBlocked` سمت سرور.
- قیمت پلن‌ها فقط از پنل ادمین.
- فیلدهای دستی روی معامله‌ی همگام‌شده در sync دست نمی‌خورند.
- وضعیت چک‌لیست در لحظه‌ی ثبت snapshot می‌شود.
- پیشرفت شاگرد فقط از تیک‌های خودش مشتق می‌شود.
- هیچ بخش جدیدی بدون ثبت در فایل تودو به ریپو اضافه نمی‌شود.
