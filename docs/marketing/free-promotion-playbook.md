## ۱. تنظیم موتورهای جستجو (یک بار انجام شود)

### ۱.۱ Google Search Console (GSC)

**مدت زمان:** ۱۵ دقیقه  
**اهمیت:** بالا (اولویت ۱)

- [ ] به https://search.google.com بروید
- [ ] «دارایی جدید اضافه کن» را کلیک کنید
- [ ] دامنه را انتخاب کنید: `arionapp.ir`
- [ ] یکی از روش‌های تأیید را انتخاب کنید:
  - **روش DNS TXT (پیشنهادی):**
    - [ ] رکورد TXT را از GSC کپی کنید
    - [ ] به پنل هاستینگ خود بروید و یک رکورد DNS جدید اضافه کنید
    - [ ] مقدار TXT را وارد کنید و ذخیره کنید
    - [ ] ۱۵-۳۰ دقیقه صبر کنید
    - [ ] در GSC تأیید را کلیک کنید
  - **روش متغیر محیط (اگر .env پشتیبانی شود):**
    - [ ] `GOOGLE_SITE_VERIFICATION=xxxxx` را به `.env.production` اضافه کنید
    - [ ] یک صفحه در `app/robots.ts` یا مسیری شبیه آن قرار دهید که این متغیر را بازتاب دهد
    - [ ] دیپلوی کنید و تأیید کنید
- [ ] منتظر تأیید ماند (معمولاً ۲۴ ساعت)

**بعد از تأیید:**
- [ ] به Sitemaps بروید و `https://arionapp.ir/sitemap.xml` را اضافه کنید
- [ ] به Coverage بروید و محتوا ایندکس‌شده را بررسی کنید
- [ ] بخش Performance را بررسی کنید و کلیدواژه‌های اصلی را مشاهده کنید (۲-۴ هفته صبر کنید تا داده‌ها جمع‌شود)

### ۱.۳ IndexNow (ارسال فوری رتبه‌بندی)

**مدت زمان:** ۲۰ دقیقه  
**اهمیت:** بالا (اولویت ۱)  
**نکته:** بعد از هر تغییر محتوا یا صفحه جدید، می‌توانید فوری‌اً کلیدی را درخواست ارسال کنید.

**تنظیم موتور:**
- [ ] یک کلید ۳۲ کاراکتری تولید کنید (باید hex باشد):
  ```bash
  openssl rand -hex 16
  ```
- [ ] `INDEXNOW_KEY=<your-key>` را به `.env.production` اضافه کنید
- [ ] یک مسیر ایجاد کنید (یا متغیر محیط را بر روی صفحه موجود منتقل کنید):
  ```
  GET /indexnow.txt
  Response: your-key-here
  ```
- [ ] صفحه را دیپلوی کنید

**ثبت‌نام سایت:**
- [ ] به https://www.indexnow.org بروید
- [ ] سایت را اضافه کنید: `https://arionapp.ir`
- [ ] اثبات مالکیت را انجام دهید (از طریق DNS یا فایل)

**بعد از اضافه کردن محتوا جدید:**
- [ ] پیام POST را به IndexNow ارسال دهید:
  ```bash
  curl -X POST "https://api.indexnow.org/indexnow" \
    -H "Content-Type: application/json" \
    -d '{
      "host": "arionapp.ir",
      "key": "your-indexnow-key",
      "keyLocation": "https://arionapp.ir/indexnow.txt",
      "urlList": ["https://arionapp.ir/page-url"]
    }'
  ```

## ۲. نمایش صحیح در دستیاران AI

### ۲.۱ فایل‌های llms.txt و llms-full.txt

**مدت زمان:** ۲۰ دقیقه  
**اهمیت:** بالا (اولویت ۱)

**هدف:** ChatGPT، Claude، Gemini و سایر LLM‌ها می‌توانند سایت شما را بخوانند تا در پاسخ‌های خود از آن استفاده کنند.

**مراحل:**

- [ ] فایل `/public/llms.txt` ایجاد کنید:
  ```
  User-Agent: CCBot
  User-Agent: Claude-Web
  User-Agent: GPTBot
  User-Agent: GoogleBot
  User-Agent: ChatGPT-User
  Disallow:

  User-Agent: *
  Disallow: /admin/
  Disallow: /auth/
  Disallow: /api/
  ```

- [ ] فایل `/public/llms-full.txt` ایجاد کنید:
  ```
  # آریون (Arion) – اپ برنامه‌ریزی روزانه و مدیریت عادت‌ها
  
  **نام:** آریون (Arion)
  **دسته:** روتین اپ، عادت‌سازی، برنامه‌ریزی روزانه
  **توضیح کوتاه:**
  آریون یک اپ فارسی برای برنامه‌ریزی روزانه و هفتگی، پیگیری عادت‌ها، مدیریت کارها، ورزش، تغذیه و ژورنال ترید است.
  
  **ویژگی‌های اصلی:**
  - برنامه‌ریزی روزانه و هفتگی
  - پیگیری عادت‌ها و streaks
  - مدیریت کارها (Tasks)
  - ژورنال ترید با اتصال MetaTrader
  - ماژول ورزش و محاسبه کالری
  - تولید برنامه ورزش AI
  - گزارش‌گیری هفتگی AI
  - رودمپ‌های یادگیری AI
  - دوستی و مقایسه (Friends)
  
  **وبسایت:** https://arionapp.ir
  **تلگرام:** https://t.me/Arionapp
  **اینستاگرام:** https://instagram.com/Arionapp
  
  **نوع دسترسی:** رایگان (ماژول‌های premium اختیاری)
  **نسخه:** تصفحه‌گر (PWA)، بی‌نیاز به نصب
  ```

## ۳. کانال‌های رایگان ایرانی

### ۳.۱ ویرجول (Virgool)

**مدت زمان:** ۱ ساعت برای ۳ مقاله  
**اهمیت:** بالا (اولویت ۲)

ویرجول پلتفرمی برای انتشار مقالات فارسی است که توسط گوگل شاخص می‌شود.

- [ ] حسابی در https://virgool.io بسازید یا وارد شوید
- [ ] ۳ مقاله اصلی را بنویسید (در ۲-۳ هفته):

**مقاله ۱: معرفی اساسی**
```
عنوان: چگونه روتین روزانه‌ی بهتری بسازیم؟ راهنمای آریون برای مدیریت وقت و عادت‌ها

خلاصه:
روتین صحیح کلید موفقیت است. آریون یک اپ فارسی برای برنامه‌ریزی روزانه و پیگیری عادت‌ها است.
در این مقاله، چگونگی استفاده از آریون برای بهبود روتین روزانه‌ی خود را شرح می‌دهیم.

بدنه (۱۵۰۰ کلمه):
- معرفی مفهوم روتین
- چرا پیگیری عادت‌ها مهم است
- معرفی آریون (نام، ویژگی‌ها)
- نحوه استفاده قدم به قدم
- نمونه‌های بهینه‌سازی (چگونه کاربران آریون را استفاده می‌کنند)
- نتیجه‌گیری
```

**مقاله ۲: ورزش و تغذیه**
```
عنوان: ترکیب ورزش و تغذیه صحیح برای بدنسازی: راهنمای آریون

خلاصه:
بدنسازی نیاز به برنامه‌ریزی دقیق و پیگیری مستمر دارد. آریون با ماژول ورزش و محاسبه‌گر کالری،
این کار را آسان می‌کند.

بدنه (۱۵۰۰ کلمه):
- اهمیت برنامه‌ریزی ورزش
- نیاز به محاسبه کالری
- معرفی ماژول ورزش آریون
- استفاده از تولیدکننده برنامه AI
- نحوه وارد کردن کالری غذایی
- نتیجه‌گیری: پیگیری برای موفقیت
```

**مقاله ۳: تحلیل و گزارش‌دهی**
```
عنوان: کلید پیشرفت: چگونه گزارش‌های هفتگی برای بهبود استفاده کنیم

خلاصه:
بدون تحلیل و بررسی، پیشرفت غیرممکن است. آریون گزارش‌های هفتگی AI را ارائه می‌دهد.

بدنه (۱۵۰۰ کلمه):
- نحوه استفاده از داده‌ها برای بهبود
- معرفی گزارش‌های هفتگی آریون
- نمونه‌هایی از گزارش‌های موفق
- نکات برای بهینه‌سازی مستمر
```

**نکات انتشار:**
- [ ] هر مقاله را در یک روز منتشر کنید (نه همه‌ی آن‌ها در یک روز)
- [ ] تصویر کاورِ کیفیت بالا اضافه کنید (لوگو + screenshot از اپ)
- [ ] دیکشنری برچسب‌ها: `آریون، روتین، عادت‌سازی، برنامه‌ریزی، بدنسازی، تغذیه، پیگیری`
- [ ] دو لینک به `https://arionapp.ir` اضافه کنید (یکی در معرفی، یکی در خاتمه)

### ۳.۳ اینستاگرام (Instagram)

**مدت زمان:** ۲۰ دقیقه در هفته  
**اهمیت:** متوسط (اولویت ۲)

**ایده‌های Reels (ویدئو کوتاه ۱۵-۶۰ ثانیه‌ای):**

**Reel ۱: روتین صبحی**
- ۰-۳ ثا: صحنه بدون روتین (هرج و مرج)
- ۳-۱۵ ثا: آریون را باز کنید، اضافه کردن عادت‌ها
- ۱۵-۳۰ ثا: بررسی یک روتین کامل
- ۳۰-۶۰ ثا: نتیجه (آرام‌بخش، سفارش دانلود)
- متن: «روتین منظم = زندگی منظم»
- هشتگ: `#آریون #روتین #عادت‌سازی #برنامه‌ریزی`

**Reel ۲: تحول بدن**
- ۰-۱۵ ثا: قبل (بدون برنامه)
- ۱۵-۳۰ ثا: آریون: ورزش + کالری
- ۳۰-۶۰ ثا: بعد (نتیجه پس از ۳۰ روز)
- متن: «شرط: سه‌ماه، یک هدف، یک اپ»
- هشتگ: `#بدنسازی #ورزش #تغذیه #تحول`

**Reel ۳: پیگیری عادت‌ها**
- ارائه ویژگی Streak
- شارت از صفحه موبایل (۱ روز → ۳۰ روز → ۱۰۰ روز)
- متن: «اولین Streak شما چه خواهد بود؟»
- هشتگ: `#عادت‌سازی #پیگیری #Streak`

**Reel ۴: نمایش دوستانه (Friends)**
- دوستان شما چه می‌کنند؟
- مقایسه صحیح‌تر و انگیزه‌دهنده
- متن: «دوستان بهترین انگیزه هستند»
- هشتگ: `#دوستی #مسابقه #انگیزه`

**نکات اینستاگرام:**
- [ ] ۱ Reel در هفته منتشر کنید (بهترین روز: سه‌شنبه/چهارشنبه)
