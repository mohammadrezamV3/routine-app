# بخش مربی نسخه‌ی 3 (بازسازی کامل UI)

طرح: بوم Claude Design «بخش مربی‌ها — طرح تازه» https://claude.ai/artifact/Fzx5hTvrk1HbaFMdmFMBZy
قرارداد داده: `lib/coachTypes.ts`. دیتابیس و APIهای قبلی (رمزگذاری سرتاسری، رتبه‌بندی، حریم خصوصی، صف انتظار، برنامه‌ها، احراز) سر جاشون می‌مونن؛ این نسخه فرانت رو از صفر می‌سازه و فقط برای قابلیت‌های تازه API اضافه می‌کنه.

## اصل‌ها
1. **سه صفحه برای مربی، یک صفحه برای شاگرد.** مربی: «امروز»، «شاگردها»، «صفحه‌ی من». هر شاگرد یک «فضا»ست. شاگرد: «مربی من» که مستقیم فضای همون مربیه (اگه چند مربی داره، اول فهرست).
2. **فضای همکاری = یک خط زمانی.** پیام‌ها، کارت برنامه (قبول/تغییر/نه داخل خود کارت)، کارت گزارش هفته، کارت هدف و بازخوردها، همه بر اساس زمان در یک ستون. بالای فضا: نام، قفل «خصوصی»، قرص هدف.
3. **واژه‌های ساده.** فقط: مربی، شاگرد، هدف، گزارش هفته، برنامه، کار، امروز، منتظر تو، روز پشت هم، مرحله، شروع با {نام}، خصوصی. ممنوع در UI: پیمان، چک‌این، صندوق، استریک، فاز، رمزگذاری سرتاسری، کلید، پیش‌نویس، نسخه، پایبندی، ماژول، احراز، رابطه، معلق، نویسه. جدول کامل واژه‌های `docs/mentor-panel-v2.md` هنوز برقراره.
4. **یک دکمه‌ی اصلی در هر صفحه**، دکمه‌ی دوم بی‌زمینه (`btn-ghost`). اصلی آخر ردیف.
5. **سبک و سریع.** بدون backdrop-filter سنگین، بدون انیمیشن بی‌نهایت، فقط transform/opacity؛ حلقه‌ها فقط `GradientRing`/`GradientArc`؛ حرکت فقط `MentorMotion` (یا کلاس‌های `app/motion.css`)؛ هر شیت/پنجره‌ی تنبل با `next/dynamic`؛ لینک داخلی فقط `SmartLink`؛ framer فقط `m as motion`.
6. همه‌ی قانون‌های ثابت CLAUDE.md: tr() برای هر متن، CSS منطقی، ارقام انگلیسی، بدون اعراب و «أ/إ»، دکمه/فیلد/تیک/اسپینر/SegmentedTabs/PageLoader فقط کامپوننت‌های سایت، بک‌گراند خودسرانه نه، فیلد با کلاس استاندارد.

## ظاهر (توکن‌ها، فقط با متغیرهای تم سایت)
- سطح کارت: `.ch-card` = گرادیان خیلی ملایم روی `--box-bg` + بوردر نازک `--surface-line`، گردی 24px (کارت بزرگ 28px). روی تم روشن همون توکن‌ها.
- آواتار: `CoachAvatar` = عکس کاربر، وگرنه حرف اول روی گرادیان پایدار از روی id (پنج جفت رنگ ثابت، روی هر دو تم خوانا) + حلقه‌ی اختیاری `GradientRing` دورش.
- هاله‌ی بالای صفحه: یک `radial-gradient` ثابت با `--accent` (کم‌رنگ)، بدون انیمیشن.
- نومو: رنگ بنفش ملایم (`--ring-2b`) با آیکون جرقه‌ی پر، فقط یک خط/کارت کوچک.
- نوار پایین مربی (موبایل): قرص شناور سه آیتمی `CoachNav` (امروز · شاگردها · صفحه‌ی من)؛ دسکتاپ: همون سه آیتم در سرتیتر صفحه.
- CSS: `components/coach.css` با پیشوند `ch-` (import در هر کامپوننت Coach* + `app/_area/mentor.css`/`mentorship.css`/`mentors.css` در صورت نیاز). فایل‌های قدیمی `components/mentor.css` تا وقتی کامپوننت قدیمی‌ای مونده حذف نمی‌شن.

## مسیرها
### مربی (`app/mentor/*`)
| مسیر | صفحه |
|---|---|
| `/mentor` | امروز: سلام + تاریخ جلالی، قرص وضعیت پذیرش (شیت `MentorAvailabilityQuick`)، کارت هیرو (حلقه‌ی «کامل امروز» + شاگرد + منتظر تو)، یک خط `hint`، فهرست «منتظر تو» (inbox، هر ردیف آواتار + نام + دلیل + فلش، زدن = فضای اون شاگرد یا شیت درخواست)، ردیف افقی آواتارهای امروز. بدون پروفایل: سه قدم شروع (پروفایل، شرایط، انتشار). |
| `/mentor/students` | شاگردها: جست‌وجو، دکمه‌ی آیکونی دعوت (شیت دعوت با نام کاربری)، `SegmentedTabs` همه / کمک لازم / نزدیک هدف، ردیف‌ها با حلقه‌ی هفته، صف انتظار جمع‌شونده ته فهرست. |
| `/mentor/students/[studentId]` | فضای همکاری (نقش مربی). منوی سه‌نقطه: هدف تازه، یادداشت من، برچسب‌ها، چیزهایی که می‌بینم، خروجی CSV، توقف/ادامه، پایان همکاری. دسکتاپ (>=1024px): سه ستون (فهرست شاگردها، خط زمانی، کنار: نومو + برنامه‌های فعال + یادداشت + «برنامه‌ی تازه»). |
| `/mentor/students/[studentId]/week?w=` | گزارش هفته: سه حلقه (روتین، تمرین، خواب)، چهار عدد، نمودار هفت روز، سه خط نومو، «ویرایش برنامه» (ghost) + «یک پیام تشویقی بده» (اصلی، شیت پیشنهادهای نومو). |
| `/mentor/programs/new?student=` | برنامه‌ی تازه: `SegmentedTabs` با نومو / از قالب / خالی، سپس ویرایشگر کارها (بازطراحی `MentorProgramEditor`، همون API). پاورقی: خلاصه + «ویرایش»/«بفرست برای X». |
| `/mentor/programs/[id]/edit`, `/duplicate` | همون ویرایشگر. |
| `/mentor/settings` | صفحه‌ی من: پیش‌نمایش صفحه‌ی عمومی + لینک کوتاه (کپی/اشتراک)، گروه ردیف‌ها: پروفایل، تایید هویت، نمایش در فهرست، پذیرش (وضعیت، ظرفیت، خوش‌آمد، سوال‌های اول کار)، کار با شاگردها (یادآور بی‌خبری، برچسب‌ها، قالب‌ها، پیام‌های آماده). هر ردیف شیت خودش. |
| `/mentor/profile`, `/mentor/templates`, `/mentor/reports` | ریدایرکت: profile → `/mentor/settings?open=profile`، templates → `/mentor/settings?open=templates`، reports → `/mentor/students`. |

### شاگرد
| مسیر | صفحه |
|---|---|
| `/mentorship` | مربی من: اگه دقیقا یک همکاری ACTIVE → کارت مربی + کارت هدف + نوار «برنامه‌ی تازه» + کارهای امروز از این مربی + «سارا چی می‌بینه؟» (ghost) + «پیام به سارا» (اصلی، به فضا). چند مربی → فهرست کارت‌ها. دعوت‌ها بالای صفحه. هیچ مربی → خالی دلگرم‌کننده + «پیدا کردن مربی». |
| `/mentorship/[id]` | فضای همکاری (نقش شاگرد). کارت برنامه‌ی منتظر جواب با «قبول» (اصلی) / «تغییر بخواه» / «نه». منو: چی می‌بینه، گزارش، پایان، مسدود. |
| `/mentorship/[id]/chat` | ریدایرکت به `/mentorship/[id]`. |
| `/mentor-programs/[id]` | جزئیات برنامه (هر دو نقش)، بازطراحی هم‌سبک. |

### عمومی
| مسیر | صفحه |
|---|---|
| `/mentors` | پیدا کردن مربی: جست‌وجو، دسته‌ها با `SegmentedTabs`، «محبوب» و «تازه» (همون API). کارت مربی تازه. |
| `/mentors/[mentorId]` | صفحه‌ی مربی (همون طرح `/c/`). |
| `/c/[username]` | لینک کوتاه: صفحه‌ی عمومی مربی SSR با متادیتا. «شروع با {نام}»: مهمان → ثبت‌نام با `callbackUrl` همین صفحه و بعد شیت درخواست (پذیرش شرایط + سوال‌های اول کار)؛ واردشده → همون شیت. |

## قابلیت‌های تازه
1. **هدف** (`MentorGoal`): مربی از منوی فضا می‌سازه (شیت: نوع با `SegmentedTabs` «جلسه‌ی تمرین در هفته» / «درصد روتین در هفته»، عدد، تعداد هفته). پیشرفت خودکار. پایان → کارت نتیجه‌ی قابل اشتراک (canvas سمت کلاینت، مثل `lib/shareCard.ts`، 1080×1350، بدون حاشیه) برای شاگرد و مربی.
2. **گزارش هفته** خودکار از داده‌ی خود شاگرد؛ خواب فقط با تیک «خواب» در «چی می‌بینه؟» (پیش‌فرض خاموش).
3. **نومو برای مربی**: پیش‌نویس برنامه، سه خط گزارش هفته، پیشنهاد پیام تشویقی (از داده‌ی هفته، نه متن گفت‌وگو).
4. **لینک کوتاه** `/c/username`.
